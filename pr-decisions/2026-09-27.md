# PR decisions, 2026-09-27

Record of merge and close decisions for SyberLabs pull requests. Written so the choices can be inspected later. Times are UTC.

## Rule used for this pass

`main` requires a GitHub approving review. A review comment in chat does not count, and branch protection was not bypassed. RISE also rejects merge commits, so merges are squash merges. After each squash, the next pull request is behind `main`, and the repository rule requires a fresh `CI` result on that updated head before the merge is allowed. Unresolved review threads also block the merge, so those threads were resolved before merging.

Stale and too far out of date means: no updates for at least 7 days, and the pull request no longer sits on current `main` (conflicts, or a base more than a week's worth of commits behind, so the last green run does not describe today's tree).
